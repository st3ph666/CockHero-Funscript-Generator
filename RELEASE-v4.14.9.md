# CockHero Funscript Generator v4.14.9

Initial GitHub publication of the v4.14.9 codebase.

## Highlights

- CockHero-oriented BPM/rhythmic generation
- Episode pattern presets
- Visual analysis workflow
- Funscript optimization and video-based generation
- Progressive initial movement handling
- Automatic dead-time detection and filling
- Previous/next cycle mixing
- Smooth transitions for generated gap movements
- Progressive end-of-video fade
- 50 optional movement patterns
- Automatic duration detection using ffprobe

## Main file

`CockHero_Funscript_Generator_v4.14.9.py`

## Requirements

Python 3, Tkinter, NumPy and FFmpeg/ffprobe.
